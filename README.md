# USB-Look-Cinnamon

[English README](README.en.md)

> **開発準備中：現在は設計仕様書のみ公開準備中で、インストールできるAppletはまだない。**

USB-Look-Cinnamonは、Linux MintのCinnamonパネルからUSB機器全般の接続状態と識別情報を確認する、軽量なオープンソースAppletを目指すプロジェクトだ。

## 計画している機能

- USBシリアル、デバッグ機器、ストレージ、HID、カメラ、オーディオ、USBネットワーク、USBハブ、その他のUSB機器を一覧表示
- VID/PID、製品名、対応するデバイスノード・ドライバの表示
- USB接続・切断イベントによる更新
- **デバイス種類別**の監視ON/OFF（個別機器ごとの設定は設けない）
- USBシリアル等について、確認可能な範囲で利用プロセス名とPIDを表示
- Cinnamon標準のシステムフォントとライト／ダークテーマに追従
- 使用状態が判断できない機器には推測せず「Unknown」を表示

USB機器の使用状態をすべての種類について統一的・完全に判断することはできない。「Not in use」は排他利用が保証されることを意味しない。

## 対象環境と設計

初期検証環境は **Linux Mint / Cinnamon 6.6.7**。Cinnamon 6.xへの互換性を検討する。CJS/JavaScriptとGUdevを中心に、追加の常駐デーモンを必須としない設計を採る。

詳しくは[設計仕様書](docs/superpowers/specs/2026-10-22-usb-look-cinnamon-design.md)を参照。

## 方針

本Appletは初期リリースではUSB機器を**読み取り専用**で監視する。USBのリセット、強制切断、プロセス終了、ファームウェア書き込み、開発プロジェクトとの紐付けは対象外。

外部サービスへのデータ送信は必要とせず、機器のシリアル番号やプロセス情報を不用意にログへ保存しない。
