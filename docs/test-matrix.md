## 機能試験

- [ ] Appletをパネルに追加・削除し、Cinnamonセッションが継続する。
- [ ] 起動時一覧とパネル件数が一致し、root hubを数えない。
- [ ] USB-UART（例: CP210x/CH340/FTDI）を挿抜し、ポート名を表示する。
- [ ] CDC ACM（例: ESP32-S3 / STM32）を挿抜し、`ttyACM`を表示する。
- [ ] USBストレージをマウント/解除し、マウント結果が更新される。
- [ ] HID、カメラ、オーディオ、USBネットワークを可能な限り確認。
- [ ] 外付けUSBハブと配下の機器を別々の物理機器として表示。
- [ ] 複合USB機器のインターフェースが一行の物理機器に集約される。
- [ ] 同型機器2台、ポート番号の付け替え、連続挿抜を確認する。
- [ ] 検索と9カテゴリ別トグルが正しく機能する。
- [ ] コピー（sysfsパス、VID/PID、デバイスノード）を確認する。
- [ ] 接続・切断通知は初期OFF、ON時は対象カテゴリのみ通知。
- [ ] ポップアップで使用中PID/プロセス名が観測され、別ユーザー/権限不足では過剰な断定をしない。
- [ ] `lsof`非搭載時にクラッシュせずUnknownになる。
- [ ] 接続直後と切断直後に古い検査結果を採用しない。
- [ ] ポップアップ閉鎖中に `lsof`・`findmnt` の定期実行がない。
- [ ] 複数パネルに配置しても設定とイベント処理が破綻しない。
- [ ] ライト/ダークテーマとシステムフォントを継承する。
- [ ] Applet再読込、ログアウト/ログイン、Cinnamon再起動でクラッシュしない。
- [ ] デバイスを開いたり、USBリセット、権限変更、ネットワーク送信を行わない。
